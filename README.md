# Family Docs Agent Bot

Telegram-бот (интеллектуальный агент) для семейного использования. Предназначен для классификации, переименования, сохранения и последующего семантического поиска документов (фотографии, PDF, сканы).

## 🚀 Основные возможности

1. **Умный приём документов (Vision):** Бот принимает медиафайлы и PDF, анализирует их с помощью `google/gemini-3.5-flash` через OpenRouter, определяет категорию, владельца и предлагает оптимальное имя для файла.
2. **Пакетный режим:** Возможность отправить несколько фотографий документов, которые бот автоматически объединит в один PDF.
3. **Хранение в облаке и локально:** Документы сохраняются на локальный диск и в Google Drive в соответствующую структуру папок (например, `Медицина/Жена/Полис_ОМС_2026.pdf`).
4. **Семантический поиск:** Поиск документов по смыслу ("найди полис жены" или "что-то про машину") на основе векторных эмбеддингов (`google/gemini-embedding-2`) в базе данных SQLite через `sqlite-vec`.

## 🛠️ Стек технологий

- **Python:** 3.13+
- **Менеджер пакетов:** [uv](https://github.com/astral-sh/uv)
- **Telegram фреймворк:** [aiogram 3.x](https://github.com/aiogram/aiogram) (асинхронный, FSM)
- **Конфигурация:** [pydantic-settings](https://github.com/pydantic/pydantic-settings)
- **База данных:** SQLite + SQLAlchemy 2.0 (асинхронная библиотека `aiosqlite`)
- **Векторный поиск:** `sqlite-vec`
- **Интеграция с LLM и Google Drive:**
  - LLM & Embeddings: Gemini через API OpenRouter
  - Google Drive: Google API Client (авторизация через Service Account)

## 📦 Быстрый старт

### 1. Подготовка окружения

Убедитесь, что у вас установлен `uv`. Если нет, установите его согласно официальной инструкции.

Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```
Заполните обязательные параметры в файле `.env` (токен бота, ключи OpenRouter, ID папки Google Drive).

### 2. Запуск проекта с помощью Makefile

Для повседневной разработки используется `Makefile`:

- **Запуск бота в dev-режиме:**
  ```bash
  make run
  ```
- **Запуск тестов:**
  ```bash
  make test
  ```
- **Запуск линтеров (ruff + mypy):**
  ```bash
  make lint
  ```
- **Автоматическое форматирование кода:**
  ```bash
  make format
  ```
- **Запуск бота в Docker-контейнере:**
  ```bash
  make up
  ```
- **Остановка Docker-контейнера:**
  ```bash
  make down
  ```

## 🐳 Деплой через Docker

Бот полностью подготовлен к развертыванию в Docker-контейнере. Для запуска выполните:

1. Убедитесь, что файл `.env` заполнен, а файл `data/credentials.json` (Service Account для Google Drive) находится на своем месте.
2. Запустите контейнер в фоновом режиме:
   ```bash
   make up
   ```
3. Логи контейнера можно посмотреть с помощью:
   ```bash
   docker logs -f tg-gocs-bot
   ```
4. Остановить бота:
   ```bash
   make down
   ```
