# Инструкция по настройке интеграции с Google Drive (Service Account)

Этот документ содержит пошаговое описание того, как настроить проект в Google Cloud Console, создать Сервисный Аккаунт (Service Account) и подключить Google Drive для автоматического сохранения документов ботом.

---

## Шаг 1: Создание проекта в Google Cloud

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/).
2. Войдите под своим Google-аккаунтом.
3. Нажмите на выпадающий список проектов в левом верхнем углу и нажмите **New Project** (Новый проект).
4. Укажите название проекта (например, `family-docs-bot`) и нажмите **Create** (Создать).
5. Дождитесь создания проекта и выберите его.

---

## Шаг 2: Включение Google Drive API

1. В левом боковом меню выберите раздел **APIs & Services** (API и службы) → **Library** (Библиотека).
2. В поисковой строке введите **Google Drive API**.
3. Нажмите на найденный **Google Drive API** и нажмите кнопку **Enable** (Включить).

---

## Шаг 3: Создание Сервисного Аккаунта (Service Account)

1. Перейдите в раздел **APIs & Services** → **Credentials** (Учетные данные).
2. Нажмите кнопку **+ Create Credentials** (Создать учетные данные) на верхней панели и выберите **Service Account** (Сервисный аккаунт).
3. Заполните данные:
   - **Service account name**: например, `drive-uploader`
   - **Service account ID**: сгенерируется автоматически.
4. Нажмите **Create and Continue** (Создать и продолжить).
5. Роли указывать не обязательно (нажмите **Continue**), затем нажмите **Done** (Готово).

---

## Шаг 4: Экспорт ключа доступа (credentials.json)

1. В списке созданных учетных данных найдите ваш созданный Сервисный Аккаунт в секции **Service Accounts** и кликните по его названию (или иконке редактирования).
2. Перейдите на вкладку **Keys** (Ключи) в верхней части экрана.
3. Нажмите кнопку **Add Key** (Добавить ключ) → **Create new key** (Создать новый ключ).
4. Выберите формат **JSON** и нажмите **Create** (Создать).
5. Файл ключа автоматически скачается на ваш компьютер.
6. Переименуйте скачанный файл в `credentials.json` и положите его в директорию `data/` в корне вашего проекта.

---

## Шаг 5: Настройка прав доступа в Google Drive

Сервисный аккаунт имеет собственный изолированный диск и по умолчанию не видит ваши личные папки. Чтобы он мог сохранять файлы в вашу папку:

1. Перейдите в свой личный Google Drive.
2. Создайте или выберите папку, в которую бот будет сохранять документы (например, `Семейный Архив`).
3. Скопируйте ID этой папки из URL браузера.
   *Например, если ссылка: `https://drive.google.com/drive/folders/1aBcDeFgHiJkLmNoPqRsTuVwXyZ`, то ID папки: `1aBcDeFgHiJkLmNoPqRsTuVwXyZ`*.
4. Нажмите правой кнопкой мыши по этой папке → **Share** (Поделиться).
5. Введите email-адрес вашего Сервисного Аккаунта.
   *Email можно скопировать из Cloud Console или из скачанного файла `credentials.json` (поле `client_email`), он выглядит примерно так: `drive-uploader@family-docs-bot.iam.gserviceaccount.com`*.
6. Убедитесь, что для аккаунта выставлена роль **Editor** (Редактор) и снимите галочку "Notify people" (Уведомить людей), после чего нажмите **Share** (Поделиться).

---

## Шаг 6: Настройка переменных окружения (.env)

Откройте файл `.env` в корне проекта и укажите:
1. Путь к файлу ключа:
   `GDRIVE_CREDENTIALS_PATH=data/credentials.json`
2. ID папки, которым вы поделились на шаге 5:
   `GDRIVE_ROOT_FOLDER_ID=1aBcDeFgHiJkLmNoPqRsTuVwXyZ` (вставьте ваш реальный ID папки).
