## Статус: ✅ Выполнена

## Предзависимость
✅ Задача 7 выполнена

## Цель
Сделать бота стабильным "навсегда" — он не должен падать ни при каких обстоятельствах.

## Что делаем

### Обработка ошибок LLM
- [x] Retry с экспоненциальной задержкой (3 попытки)
- [x] Timeout на запрос (30 сек)
- [x] Fallback сообщение пользователю при недоступности модели

### Обработка ошибок Google Drive
- [x] Retry при сетевых ошибках
- [x] Продолжить работу если Drive недоступен (сохранить только локально)
- [x] Уведомить пользователя: "Сохранил локально, Drive временно недоступен"

### Валидация входных данных
- [x] Проверка формата файла (только фото + PDF)
- [x] Ограничение размера файла (настраивается в конфиге, напр. 50 МБ)
- [x] Защита от спама: rate limiting на пользователя

### Очистка ресурсов
- [x] Гарантированная очистка временных файлов (даже при ошибке)
- [x] Правильный сброс FSM состояния при любом исходе

### Логирование
- [x] Структурированные логи (уровни: DEBUG, INFO, ERROR)
- [x] Логировать все ключевые события: получен файл, классифицирован, сохранён, ошибка
- [x] Не логировать персональные данные

### Тесты
- [x] `tests/test_reliability.py` — сценарии: LLM упал, Drive недоступен, файл слишком большой, неверный формат

## Критерий готовности

```bash
make test  # все тесты зелёные, включая test_reliability.py
# При ручном тесте: отправить файл 100 МБ → бот вежливо отказывает
# При выключенном интернете → бот сохраняет локально и сообщает об этом
```
