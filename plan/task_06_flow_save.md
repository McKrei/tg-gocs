# Задача 6 — Flow 1: Умный приём и сохранение документа

## Статус: ✅ Выполнена

## Предзависимость
✅ Задача 5 выполнена

## Цель
Реализовать главный сценарий бота end-to-end: получить файл → классифицировать → подтвердить → сохранить.

## Что делаем

- [ ] **Приём файла:** скачать во временную папку, запустить FSM `processing_document`
- [ ] **Немедленный анализ:** передать файл в Gemini Flash (vision), получить Draft
- [ ] **Draft сообщение:** отправить пользователю предложение с inline-кнопками:
  - `[✅ Сохранить так]`
  - `[📎 Склеить и сохранить]` (если >1 файла)
  - `[📁 Выбрать другую папку]`
  - `[❌ Отмена]`
- [ ] **Пакетный режим:** пользователь шлёт ещё файлы → добавляются в сессию, Draft обновляется
- [ ] **Текстовая корректировка:** "нет, это полис мужа" → модель понимает, обновляет Draft
- [ ] **Финальное сохранение:**
  - `convert_to_pdf` если нужно склеить
  - `save_to_local_and_drive` — локально + Google Drive
  - Запись в SQLite + генерация эмбеддинга
  - Уведомление об успехе
- [ ] **TTL-таймаут:** сессия сбрасывается через 30-60 мин неактивности
- [ ] `tests/test_flow_save.py` — сквозной тест сохранения (мок Drive + LLM)

## Пример диалога
