## Цель
Реализовать умный поиск документов по смыслу: пользователь пишет запрос → бот находит и присылает файл.

## Что делаем

- [x] **Детектор намерения:** если в `idle` пришёл текст — определить, это поиск или что-то другое
- [x] **Векторный поиск:**
  - Сгенерировать эмбеддинг запроса через gemini-embedding-2
  - Найти топ-5 документов в SQLite через sqlite-vec
- [x] **Re-ranking через LLM:** Gemini Flash выбирает лучший результат из топ-5, объясняет выбор
- [x] **Ответ пользователю:**
  - Прислать сам файл в чат
  - Ссылку на Google Drive
  - Краткое описание документа
- [x] **Fallback:** если ничего не найдено → предложить уточнить запрос
- [x] `tests/test_flow_search.py` — тест поиска (мок эмбеддингов + БД с тестовыми данными)
