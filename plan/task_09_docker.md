## Цель
Упаковать приложение в Docker-контейнер для production-запуска одной командой.

## Что делаем

- [ ] `Dockerfile` — multi-stage сборка (builder → runtime), минимальный образ
- [ ] `docker-compose.yml`:
  - Сервис `bot`
  - Volume `./data:/app/data` — БД, файлы, credentials.json
  - Volume `./src:/app/src` — исходники (для удобной разработки)
  - Передача `.env` переменных
- [ ] `.dockerignore` — исключить лишнее из контекста
- [ ] Проверка что `make up` запускает всё с нуля
- [ ] Проверка что данные сохраняются между рестартами контейнера
- [ ] Обновить `README.md` — секция "Деплой через Docker"

## Структура Docker

```
FROM python:3.12-slim AS builder
# установка uv, зависимостей

FROM python:3.12-slim AS runtime
# только runtime зависимости, исходники
CMD ["python", "-m", "src.bot.main"]
```

## Критерий готовности

```bash
make up  # контейнер запускается, бот отвечает
# Рестарт контейнера → данные в SQLite сохранились
docker logs tg-gocs-bot  # логи выводятся корректно
```
